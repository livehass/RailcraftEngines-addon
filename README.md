# Railcraft Engines

Railcraft Engines is an unofficial addon that brings the classic Railcraft steam engines to Minecraft 1.21.1. It requires Railcraft Reborn and adds the Hobbyist, Commercial, and Industrial Steam Engines.

## Features

- Hobbyist Steam Engine: burns solid furnace fuel and uses water to generate steam internally.
- Commercial Steam Engine: consumes external steam to generate energy.
- Industrial Steam Engine: consumes external steam to generate more energy.
- Animated engine pistons, energy stages, and engine GUIs.
- Engine recipes and a dedicated creative inventory tab.
- Fluid and item automation support for the Hobbyist engine.

The Hobbyist engine uses its internally generated steam for its own operation. It does not expose that steam for extraction.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.x
- Railcraft Reborn 1.2.10 or a compatible release in the 1.2.x series

JEI is optional. It can display the engines' crafting recipes.

## Installation

1. Install NeoForge for Minecraft 1.21.1.
2. Install a compatible version of Railcraft Reborn.
3. Place the Railcraft Engines JAR in the instance's `mods` folder.
4. Install the same required mods on both the client and the server when playing multiplayer.
